# Provenance

## Overview

MethylCurate maintains useful provenance for the actions it takes when retrieving data, harmonzing metadata, performing quality control steps, or running pre-existing epigenetic aging clocks. Provenance can be thought of as a structured, inspectable record of how MethylCurate produced a particular outcome, including the inputs it observed, the tokens used, the outputs generated, and the steps at which these actions were taken.

## Outputs

### Provenance File 

The provenance file can be found at `<output_root>/logs/provenance.jsonl`.
